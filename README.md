# XenForge

XenForge enables distributed, scalable infrastructure management through real-time auto-scaling and processing with a centralized Manager and API Gateway.

XenForge is built to be simple and practical, focusing on doing one thing well.

**Why XenForge?**

- XenForge enables distributed, scalable infrastructure
- management through real-time auto-scaling and
- processing with a centralized Manager

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/XenForge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure XenForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
